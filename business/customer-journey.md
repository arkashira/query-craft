 # Customer-Journey.md

## Aware

### Trigger Event
Data engineers and analysts encounter repetitive SQL queries that consume significant time and resources, hindering their ability to focus on strategic work.

### Friction Points

- Time-consuming manual query creation and execution
- Difficulty in maintaining query consistency across teams
- Lack of a centralized repository for query management

### User Emotions

- Frustration due to time wasted on repetitive tasks
- Anxiety about potential errors in queries
- Dissatisfaction with current solutions

### Opportunities to Delight

- Introducing a tool that automates and streamlines ad-hoc SQL queries
- Providing a centralized repository for query management
- Offering query consistency across teams

### Metric per Phase

- Awareness Level: Number of data engineers and analysts expressing the pain point

## Consider

### Trigger Event
Data engineers and analysts start researching solutions to automate and streamline ad-hoc SQL queries.

### Friction Points

- Overwhelming number of available tools
- Lack of clear differentiators between tools
- Difficulty in evaluating the effectiveness of each tool

### User Emotions

- Skepticism about new tools
- Caution due to potential implementation challenges
- Excitement about the potential to save time and resources

### Opportunities to Delight

- Providing clear and concise product information
- Offering a free trial or demo
- Highlighting success stories and case studies

### Metric per Phase

- Consideration Level: Number of data engineers and analysts researching the tool

## Try

### Trigger Event
Data engineers and analysts decide to try the query-craft tool.

### Friction Points

- Complexity of installation and setup
- Learning curve for using the tool
- Difficulty in integrating the tool with existing systems

### User Emotions

- Anticipation about the potential benefits
- Frustration during the learning process
- Dissatisfaction if the tool does not meet expectations

### Opportunities to Delight

- Providing comprehensive documentation and tutorials
- Offering dedicated customer support
- Providing a user-friendly interface

### Metric per Phase

- Trial Level: Number of data engineers and analysts using the tool on a trial basis

## Adopt

### Trigger Event
Data engineers and analysts decide to adopt the query-craft tool as a regular part of their workflow.

### Friction Points

- Ongoing maintenance and updates
- Integration with other tools and systems
- Ensuring data security and compliance

### User Emotions

- Satisfaction with the tool's performance
- Relief from the burden of repetitive SQL queries
- Confidence in the tool's ability to support strategic work

### Opportunities to Delight

- Providing regular updates and improvements
- Offering integrations with popular data tools and systems
- Ensuring data security and compliance

### Metric per Phase

- Adoption Level: Number of data engineers and analysts regularly using the tool

## Expand

### Trigger Event
Data engineers and analysts start using the query-craft tool for more complex queries and data analysis tasks.

### Friction Points

- Scalability of the tool for larger datasets
- Complexity of advanced query features
- Difficulty in collaborating with other data teams

### User Emotions

- Excitement about the tool's potential for more complex tasks
- Frustration if the tool does not scale well
- Dissatisfaction if collaboration features are lacking

### Opportunities to Delight

- Providing scalable solutions for larger datasets
- Offering advanced query features
- Enhancing collaboration features

### Metric per Phase

- Expansion Level: Number of data engineers and analysts using the tool for more complex tasks and data analysis
